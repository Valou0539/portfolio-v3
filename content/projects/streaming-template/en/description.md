This template was provided by a client, and we had to implement new features and fix many bugs before putting their website online. Today, this streaming platform has over 60,000 registered users and we continue to improve it regularly. Previously, the template only offered login via Discord and stored movie and series data internally. The first features we had to implement were therefore a secure, traditional authentication system and the integration of the [TMDB](https://www.themoviedb.org/) API to retrieve movie and TV series data.
